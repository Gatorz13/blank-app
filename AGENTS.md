# Hush Homepage Guardrails

## What Hush is
Hush is a **payments-native privacy L1 for stablecoin settlement**.

## What Hush is not
- Not a generic privacy chain
- Not a zkVM
- Not a public-chain overlay

## What the homepage visual must prove
The visual must prove: **same payment activity, different visibility outcome**.

## What to avoid
- Line charts
- Generic fintech dashboards
- Report-style figures
- Decorative UI
- Gradients
- Glow
- “Same chart recolored”

## What success looks like
A cold viewer understands in ~3 seconds that:
- Public rails turn payment activity into inferable financial intelligence
- Hush preserves private state and only reveals scoped receipts when needed

## Style rules
Dark, flat, institutional, minimal, no fluff.

## Codex workflow rule for this task type
Before generating SVG for ambiguous/high-leverage visuals:
1. Restate the Hush thesis in your own words
2. Propose 3 visual metaphors
3. Choose one and outline structure
4. Then generate the SVG
